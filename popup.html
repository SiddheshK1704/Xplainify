To use Xplainify, you need a free Google Gemini API key. Your key is stored securely in your browser and never sent to our servers.

  1. Click Get API Key below to visit Google AI Studio.
  2. Sign in with your Google account.
  3. Create an API key in a new or existing project.
  4. Copy the generated key.
  5. Click Open Settings to paste and save it.
